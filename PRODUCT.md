# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Self-directed piano beginners of any age who want to play familiar songs and are beginning to learn musical notation.

## Product Purpose

Keypath helps beginners learn piano songs while starting to understand standard sheet music. The prototype succeeds when a beginner can use it to learn a first song and begin recognizing how its notes are written.

## Positioning

Keypath pairs beginner-friendly number notation with conventional staff notation and the corresponding piano keys. Learners can start with the number cue while seeing and hearing how the same notes appear in sheet music and on the keyboard.

## Operating Context

- Learning is self-paced through a web-based experience.
- A learner can choose a built-in song and practise its notes, or open a separate free-play piano to explore without a song.
- Practice history and profile details are currently stored in the learner's browser.
- The project is being developed as a website first. A separate application is a possible later direction if the web version proves useful.

## Capabilities and Constraints

- The prototype has Home, Song library, Play piano, and How it works pages.
- It includes ten built-in traditional or public-domain melodies arranged across introductory practice levels.
- Song notation is currently limited to simplified treble-clef melodies in C major. Number notation uses scale degrees, with C as 1.
- Number notation and staff notation are rendered from the same note sequence. Learners can select individual song numbers to jump to a note.
- The song keyboard, standalone two-octave free-play keyboard, and playback use browser-generated tones. Playback tempo can be adjusted from 50 to 130 BPM.
- The profile supports name, age, optional gender, and a profile photo. Practice activity is shown as a year-style calendar with a daily streak. The first-visit discovery question is optional and appears once per browser.
- The current prototype has no account system, server-side profile storage, music upload, automatic note recognition, or audio-based playing feedback.
- Expanding the song library is a future direction; more instruments and a separate application are not part of the current web prototype.

## Evidence on Hand

- A runnable React, TypeScript, and Vite web prototype in this project.
- Ten built-in song note sequences and their corresponding number and staff displays.
- No user research, external testimonials, or product validation results are recorded in the project yet.

## Product Principles

- Let beginners start playing before they are fluent at reading sheet music.
- Keep number notation, staff notation, and piano keys consistent with the same underlying notes.
- Help learners build toward reading conventional notation while they practise songs.
- Let learners practise at a pace and in an order that suits them.

## Accessibility & Inclusion

- The intended audience includes beginners of any age.
- No specific accessibility standard or additional product-specific accommodation has been established yet.
