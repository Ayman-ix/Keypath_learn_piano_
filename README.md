# Keypath piano prototype

A small piano learning website prototype built with React, TypeScript, and Vite.

## Run it on your Mac

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open this folder in VS Code.
3. In VS Code, open **Terminal → New Terminal**.
4. Run `npm install` once, then `npm run dev`.
5. Open the local address printed by Vite (usually `http://localhost:5173`).

To stop the site, press `Control+C` in the terminal.

## What's included

- Ten public-domain and traditional melodies, arranged in gradual practice levels.
- A simplified treble staff and number notation generated from the same notes, with an expandable beginner guide to staff lines, middle C, and number mapping.
- Separate Home, Song library, and How it works pages with animated navigation.
- Clickable song numbers for direct note jumping, plus a learner profile saved locally in the browser.
- A past-year practice calendar with daily streaks, profile photo, age, and optional gender; the discovery question appears once for new visitors.
- A two-octave clickable keyboard with browser-generated tones.
- Listen, pause, step forward/back, reset, and adjustable playback tempo (50–130 BPM, including during playback).
- Responsive layout for desktop and smaller screens.

The sounds are simple synthesized tones for this prototype. The staff display is a basic melody view, not engraved or publication-ready sheet music. The displayed number system uses scale degrees in C major, with C as 1.
